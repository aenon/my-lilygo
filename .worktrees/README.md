# Git worktrees for this repo

Each active line of work uses **one branch** and **one directory** here, per **`AGENTS.md`** (1:1:1 branch ↔ worktree ↔ PR).

Naming: `.worktrees/<branch-with-slashes-replaced-by-dashes>`  
Example: branch `feat/photo-slideshow` → `.worktrees/feat-photo-slideshow`

This directory’s contents are ignored by Git except this file.
